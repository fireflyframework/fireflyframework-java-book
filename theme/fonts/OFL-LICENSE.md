**SIL Open Font License, Version 1.1** (OFL-1.1), which permits bundling and
redistribution with the work:

- **Maven Pro** — body text and headings.
  Copyright © The Maven Pro Project Authors. Source: <https://github.com/googlefonts/mavenproFont>
- **JetBrains Mono** — code listings and the cover's `flatMap()` label.
  Copyright © 2020 The JetBrains Mono Project Authors. Source: <https://github.com/JetBrains/JetBrainsMono>

The full OFL-1.1 text accompanies each font at its upstream source above and at
<https://openfontlicense.org>. The fonts are embedded (base64) in `theme/fonts.css`
so the EPUB and PDF render identically everywhere; the `.ttf` files here are the
sources for that embedding and for local cover rendering.
